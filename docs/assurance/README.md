# `docs/assurance/`

- **Purpose:** EAL4-ready assurance material: architecture, TSFI, design, CM, tools, trace matrix.
- **License:** CC-BY-4.0

| File | Content |
|---|---|
| `tools.md` | The tools that build, check and test the project: pinned versions (the table is generated by `./x tools-doc` from `tools/toolchain.env` and `tools/requirements.txt`), use, installation, options and the reason for each choice. |
| `cm.md` | The configuration management as practised: branches, commits, generated files, the checks of the CI, the pinned toolchain, licences and provenance, review; and the decisions still open. |
| `trace-matrix.md` | The requirement trace matrix, generated by `./x trace` from `docs/requirements/` and the `@req` and `@verifies` markers. Not edited by hand. |
