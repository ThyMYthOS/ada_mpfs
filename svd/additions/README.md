# `svd/additions/`

- **Purpose:** Blocks without register documentation (mandatory header: source/status/owner): PLIC (`plic.yaml`), CLINT (`clint.yaml`), the PLIC interrupts (`interrupts.yaml`) and the hart-local interrupts (`local_interrupts.yaml`, own schema, not merged into the SVD). Files other than `local_interrupts.yaml` must be listed in `svd/device.yaml`, in dependency order.
