# `tests/host/`

- **Purpose:** Host tests (`<suite>/run.sh`; non-zero exit code on FAIL), run by `./x test host`.
- **License:** Apache-2.0

| Suite | Content |
|---|---|
| `x/` | The verbs and option validation of `./x`. |
| `svd/` | SVD merge, check rules, probe. |
| `pac/` | Register package generator on fixtures, and properties of the committed `libs/mpfs_pac/src/generated`. |
| `bare/` | The QEMU smoke test (with a stand-in for QEMU), `tools/metrics.sh` (with stand-ins for size and readelf) and the committed `metrics.golden`, each with negative cases. |
| `negative/` | `tests/negative/run_negative.sh` against stand-ins for the compiler driver and gprbuild: ABI mismatch accepted, a failure for another reason, a leftover image, a missing fixture or object, a fixture that lost its fault, malformed lists. |
| `analyze/` | `tools/analyze.sh` with a stand-in for adalang_analyzer: no analyzer, another version, no baseline, a silent analyzer, a new finding, the two rule sets and their baselines, `--update-baseline` (also with an analyzer that writes nothing), empty and malformed lists. |
| `hw/` | The scripts of `hw/` and `./x hw` against a stand-in for the OpenOCD telnet port (`fake_ocd.py`), files for the serial ports and a stand-in SoftConsole, with the pinned RISC-V compiler: `--expect` that matches (0) and that does not (1), set-up errors (2: no OpenOCD, no serial port, wrong or missing toolchain version, bad `lab.conf`, bad arguments), the UART stand-in only on request, a trap in the report; Ctrl+C: the scripts exit 130 at once against an OpenOCD stand-in that stops answering, and `start_openocd.sh` ends a stand-in OpenOCD that ignores SIGINT and SIGTERM within its grace period without leaving it behind. |
| `prove/` | `tools/prove.sh`: with a stand-in for gnatprove (another version, unproved checks, no summary, a failing exit status, a medium message, a missing project, a bad list); with the pinned gnatprove, the committed projects prove and a project with an unprovable overflow fails. The cases with the real gnatprove are reported as skipped when it is not installed. |
| `trace/` | `tools/trace.py` on fixture trees: the matrix, every way the check fails, the comment styles, and the committed catalogue. |
| `stack/` | `tools/stack_report` on `.su`/`.ci` fixtures with known frames, a recursion, a dynamic frame and a call into code without a frame (the summed chain is checked; a missing directory, no `.su` files and no argument fail), and `./x stack` on a copy of the tree: the real compiler on an example, and an example that ignores `STACK_ANALYSIS`, which must fail. |
| `rts_packs/` | `crates/bb-runtimes/build_rts.py` (only `mpfs` with `--hart e51\|u54`; other boards, no hart class and an unknown one are rejected; ISA switches, no `-T`, no linker script; the output does not depend on the order in which the file system lists a directory), the licenses of the fork (the Python files are GPL-3.0-or-later without the exception; the files annotated `LicenseRef-Ada-RM-permissive` in `REUSE.toml` are exactly those whose notice is the Ada Reference Manual paragraph and no GPL paragraph, 73), no committed pack and the format of `crates/mpfs_rts/packs.sha256`, `make_packs.sh --ensure` (generates the six packs, leaves current ones alone, regenerates a missing, a corrupt and another pack, warns when the hash file does not match the sources), `--check` (regenerated == committed hashes, also with another umask, time zone and working directory; a changed, a missing, a stale and an unsorted hash and a missing hash file fail), the generated packs (names, license texts, no objects, sorted entries, fixed owner and time), and `compare_toolchain.sh` against the pinned toolchain (a changed, a missing and an added common source and an FPU source that is not the soft-float one fail, a changed port unit is allowed). Needs zstd and GNU tar; the toolchain cases are skipped when the pinned GNAT is not installed. |
| `qemu_tests/` | `tests/qemu/run_tests.sh` against a stand-in for QEMU: every way a test can pass or fail (verdict, FAIL line, hang, stray port output, `console.expected`, xfail signature, malformed list, old QEMU). |
| `repro/` | `tools/repro.sh` on a fixture tree with a stand-in `./x` and stand-ins for the toolchain directories: the same input twice passes; an image that embeds its build directory or changes from run to run fails and is named; a missing or incomplete toolchain, a failing build, a build without an image, an image in one copy only, no example, no epoch and an argument fail; the examples carry the prefix map. |
| `docs/` | `tools/check_docs.py` on fixture trees: a good tree (every kind of link, the skipped directories broken); a missing file, a missing anchor (other file and same file), a reference without a definition, a link over two lines and an HTML `src` fail with file, line and link; links in code blocks, inline code and comments are ignored; a root without Markdown files, a missing root and bad arguments fail; the committed documentation passes. |
| `report/` | The shared `Host_Report` package (`common/`): a program whose checks hold exits 0; a failed check, no check, a missing `Finish` and an unhandled exception each exit non-zero. |

## `Host_Report`

Native Ada host tests use `common/host_report.ads` (`with` its directory in `Source_Dirs`). It prints the lines of the target tests (`TEST <name>: START`, `ok:`, `FAIL:`, `TEST <name>: PASS|FAIL`) and fails closed: `Start` sets the exit status to failure, and only a `Finish` after at least one check, none of which failed, sets it to success. Shell suites report with their own `pass`/`fail` functions and exit non-zero when a case failed.
